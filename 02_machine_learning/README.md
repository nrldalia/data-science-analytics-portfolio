# 🤖 Machine Learning & Multivariate Analysis

## Why This Notebook Was Created
Machine learning and multivariate analysis can often feel abstract when studied purely through matrix math. I built these notebooks to visualize how algorithms actually behave under the hood—using **Linear Regression** to map feature weights to continuous values, and **K-Means Clustering** to group multi-dimensional customer behaviors into clear operational segments.

## What's Inside
* `regression_house.ipynb`: Predicts continuous targets using Scikit-Learn Linear Regression and evaluates model performance via $R^2$ and MSE.
* `clustering_customer.ipynb`: Uses feature scaling (`StandardScaler`) and unsupervised learning to segment customers based on income and spending habits, plotting cluster centroids.
