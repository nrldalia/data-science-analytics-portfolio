# 🤖 Machine Learning & Multivariate Analysis

**Project 02 | Beginner · Python · scikit-learn · Supervised & Unsupervised Learning**

This folder contains two introductory machine-learning projects designed to demonstrate different analytical goals: **predicting a numerical outcome** and **discovering patterns in unlabelled data**.

## 🗂️ Explore the Projects

| Project | Approach | Notebook |
| :--- | :--- | :--- |
| [🏠 Housing Value Prediction](./Housing_Prediction/README.md) | Supervised learning using Linear Regression on California Housing data | [HousingAnalysis.ipynb](./HousingAnalysis.ipynb) |
| [🛍️ Customer Segmentation](./Customer_Segmentation/README.md) | Unsupervised learning using K-Means on synthetic retail customer data | [CustomerRetailAnalysis.ipynb](./CustomerRetailAnalysis.ipynb) |

## 🎯 Learning Objectives

- Prepare and validate data for machine learning
- Select suitable features and preprocessing steps
- Compare regression predictions with a baseline and evaluate MAE, MSE, RMSE and R²
- Standardise clustering inputs and evaluate candidate clusters using inertia and silhouette score
- Visualise findings and discuss assumptions, limitations and potential business uses

## 🛠️ Technologies

Python, pandas, NumPy, Matplotlib, seaborn, scikit-learn and Google Colab / Jupyter Notebook.

## ▶️ How to Run

Open either notebook in Google Colab or Jupyter, install packages from [requirements.txt](./requirements.txt) if needed, and run the cells in order. Generated output files may be written to an `outputs/` directory during execution.

**Note:** The notebooks remain in this folder to preserve existing links. Each dedicated subfolder contains the corresponding project documentation.

Both projects are **educational demonstrations**: the housing model is not a property valuation tool, and synthetic customer clusters are not validated real-world segments.
