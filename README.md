## 🚚 Featured Visualisation: FlowTrade Logistics

**FlowTrade Logistics** is an independent, logistics-inspired Power BI portfolio project built with **synthetic data**. It demonstrates how shipment, carrier, delay, and financial information can be modelled into a report that supports operational and commercial decision-making.

The report contains three connected pages:

1. **Executive Overview** — Shipment status, on-time delivery rate, delay incidence, revenue, profit, and carrier revenue contribution.
2. **Operational Performance** — On-time versus late deliveries, recorded delay incidence by mode and carrier, and delay hours per shipment.
3. **Freight Financial Performance** — Revenue-to-profit waterfall, carrier financial matrix, profit margin comparisons, and revenue-versus-margin analysis.

### 📊 Dataset and headline metrics

The synthetic dataset includes **600 shipments** across **Air, Road, and Sea** transport modes and **six carriers**.

| Metric | Result |
| :--- | ---: |
| Total Shipments | 600 |
| Delivered Shipments | 477 |
| On-Time Delivery Rate | 82.81% |
| Recorded Delay Incidence Rate | 15.17% |
| Freight Revenue | $931,991.42 |
| Freight Profit | $229,600.77 |
| Freight Profit Margin | 24.64% |

**Definitions matter:** On-time delivery rate is calculated from delivered shipments, while recorded delay incidence measures shipments with a recorded delay event out of all shipments. These are distinct operational indicators.

### 🧭 Interactive reporting features

- Synchronized **Carrier** and **Transport Mode** slicers
- Page navigation and **Reset Filters** controls
- Cross-filtering between visuals
- Transport-mode-to-carrier drill-down
- Carrier-level drillthrough to financial performance
- Conditional formatting for comparative profit margins
- Consistent earthy dashboard styling 🌿
