# 🌤️ Automated Weather Analysis & Email Reporting Pipeline

Hey there! 👋 I built this project to practice turning raw time-series data into a fully automated data science workflow. 

Instead of doing everything manually in Jupyter Notebook, this project strings together **data cleaning, statistical analysis, trend visualization, and email automation** so that insights get delivered straight to an inbox automatically. It's a snapshot of how I bridge data engineering with everyday analytics!
